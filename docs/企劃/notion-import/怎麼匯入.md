## 步驟

### 1. 建專案首頁（1 分鐘）
1. Notion 左側「＋ 新增頁面」→ 標題 **🎮 噴漆闖關 SPRAY RUN**
2. 頁面最上面貼這幾行：
   - 遊戲：https://fishon100.github.io/pinball-sling/street/
   - 程式與規則：https://github.com/fishon100/pinball-sling
   - 開發流程：https://github.com/fishon100/game-dev-flow-template
   - 目前版本：v3.7.3

### 2. 匯入 6 個 CSV（每個約 1 分鐘）
在專案首頁裡，**每個檔案做一次**：
1. 頁面空白處輸入 `/import`（或左側選單「匯入」）→ 選 **CSV**
2. 選檔案 → 會變成一個資料庫（標題就是檔名）
3. 確認它在 🎮 專案首頁底下（不在的話拖進去）

### 3. 調整欄位類型（點欄位名稱 → 「編輯屬性」→ 類型）

| 資料庫 | 改成「選項」 | 改成「多選」 | 改成「日期」 | 改成「數字」 | 改成「網址」 |
|---|---|---|---|---|---|
| 申請單確認 | 狀態 | 影響功能 | | | GitHub、預覽 |
| 開發日誌 | 類型 | | 日期 | | |
| 回饋 | 等級、狀態 | | | 輪次 | |
| 知識庫 | 類別 | | 最後同步 | | |
| 素材 | 類別、狀態 | | | | Figma |
| 需求池 | 優先、狀態 | | | | |

### 4. 加看板（1 分鐘）
「申請單確認」→ 右上「＋ 新增檢視」→ **看板** → 分組依「狀態」。
企劃每天看這個看板：**待同意**那一欄就是等你處理的。

### 5. 知識庫的內文（選做，每頁 30 秒）
CSV 只會帶入標題和欄位，內文要另外貼：
1. 在 Obsidian 打開 `知識庫.csv` 最後一欄寫的那份筆記 → `Ctrl+A`、`Ctrl+C`
2. 在 Notion 打開同名那一列 → 貼上
3. 先做最常用的：**名詞與命名總表**、**數值總表**、**劇情腳本**

> 之後換回自己的 Claude 帳號、連上 Notion 後，說「同步知識庫」，AI 會自動補齊，也可以先跳過這步。

## 做完之後

- 回饋、需求從現在起寫在 Notion；Obsidian 的 `回饋.md` 不用再寫
- 換回自己的 Claude 帳號並連上 Notion 後，對 AI 說「**接上 Notion 工作區**」：AI 會找到這 6 個資料庫，把 ID 寫進 GitHub 的 `docs/notion.json`，之後「看回饋」「開申請單」「結案」都會自動讀寫 Notion
- 在那之前，用現在這個帳號的 AI 讀不到 Notion：要它處理回饋時，把 Notion 的內容複製貼給它
