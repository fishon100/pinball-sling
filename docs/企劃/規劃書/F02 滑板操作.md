# F02 滑板操作（Paddle）— 預設操作
> **正式規則（Spectra）**：[paddle-control](https://github.com/fishon100/pinball-sling/blob/main/docs/spectra/specs/paddle-control/spec.md)（英文規則＋中文說明）。這份規劃書改為背景說明；要改規則請開申請單。
> 主架構：00 主架構規劃書・相關：F03 經典擋板操作、F04 發射桿、F15 難度與平衡

## 目的
經典兩支擋板要抓時機、手機要兩手、電腦滑鼠來不及點（回饋第 5 輪）。滑板只要**追著球移動**，一根手指或滑鼠就能玩。

## 玩家體驗
- 手機：手指左右滑；電腦：**移動滑鼠就好，不用點**（滑鼠移出遊戲畫面也會跟著）；鍵盤 ←／→
- 打在滑板**中間**直直往上，越靠**邊邊**越斜 → 可以瞄準
- 擊球回饋：滑板壓扁發光、接觸點往出球方向噴漆；打邊邊更大更亮並顯示 ↖／↗；震動 16～24ms
- 遊玩中滑鼠游標隱藏

## 功能系統
- 尺寸：一般關卡＝**中**；首領關＝**小**；道具「寬板」作用中＝**大**
- 移動範圍：整個台面寬（左牆 x=20 到發射道內牆 x=340）
- 滑板模式的台面底部**沒有彈弓與漏斗**，整片打開；球從滑板旁掉下去＝掉球
