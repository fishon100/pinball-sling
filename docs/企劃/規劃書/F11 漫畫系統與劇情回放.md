# F11 漫畫系統與劇情回放（Comic／Gallery）
> **正式規則（Spectra）**：[comics-and-story-replay](https://github.com/fishon100/pinball-sling/blob/main/docs/spectra/specs/comics-and-story-replay/spec.md)（英文規則＋中文說明）。這份規劃書改為背景說明；要改規則請開申請單。
> 主架構：00 主架構規劃書・**內容（單一來源）**：劇情腳本、劇情大綱、角色卡
（參考圖「劇情參考-格漫畫範例.png」只放在 Obsidian）

## 目的
用格漫畫說童話故事、當關卡轉場（第 4 輪：背景框 → 角色 → 對話框依序帶出）。

## 功能系統
### 演出規則
| 規則 | 實作 |
|---|---|
| 依序帶出 | 框 0～0.32 秒 → 角色彈入（0.28 秒起、每個隔 0.12） → 旁白 0.45 秒 → 對話框（0.62 秒起、每句隔 0.3）＋打字機 34 字／秒 |
| 先全景後特寫 | 每段第一格是場景大圖 |
| 大格慢、小格快 | 情緒點整列大格、動作並排小格 |
| 事件 → 無聲 → 反應 | 關鍵處留一格沒有對白 |
| 對話框 | 閱讀順序、尾巴指向說話者頭部、不蓋臉、不出框、≤32 字 |
| 回憶 | 泛黃＋網點 |
| 中文斷行 | 標點不放行首 |
- 操作：點一下＝補完這一格 → 下一格 → 翻頁；右上「跳過劇情」
- 播放時機：第一次一定播；首領前的每次都播；看過的記在存檔 `seenComic`

### 劇情回放
地圖「📖 劇情回放」：16 段依順序列出，看過的可點來重看

### 背景場景
cityGrey、cityColor、notice、wallPaint、room、window、arcade、arcadeNight、arcadeLit、machine、machineGlow、machineDark、unplug、tableMagic、alleyNight、alleyColor、subway、subwayColor、chalk、rooftop、rooftopColor、riverside、riversideColor、signature、memoryWall、memoryGrey、bigwall、bigwallColor、black

## 使用的外部工具
| 用途 | 工具 |
|---|---|
| 台詞草稿 | ChatGPT／Claude → 劇本修訂（劇情腳本） |
| 角色、背景圖（正式） | ChatGPT（GPT Image）／Midjourney → Figma（美術素材清單） |
| 漫畫演出研究 | 漫畫分格教學網站（節奏、對話框、場景大圖） |

## 介面
U-comic 漫畫層（點一下前進）、U-comic-skip 跳過按鈕、U-gallery 劇情回放頁

## 元件
角色（小葵、噴噴、阿鰭、灰先生、配角）、30 種背景、對話框、旁白框

## 程式位置
`comic.js`（播放、畫格、對話框、角色繪圖）；`data.js`：`SR.COMICS`、`SR.COMIC_TITLES`、`SR.SPEAKERS`、`SR.storyBefore／storyAfter`；`game.js`：`playStory`、`comicGallery`
