# F12 介面（畫面與 HUD）
> **正式規則（Spectra）**：[game-ui](https://github.com/fishon100/pinball-sling/blob/main/docs/spectra/specs/game-ui/spec.md)（英文規則＋中文說明）。這份規劃書改為背景說明；要改規則請開申請單。
> 主架構：00 主架構規劃書・各畫面的內容在對應功能規劃書，這裡管「有哪些畫面、怎麼串」

## 畫面流程
```
開場動畫（第一次）→ 標題 → 地圖 → [漫畫] → 關卡開場 → 遊玩 ⇄ 暫停
   → 過關演出 → 結算 → 重玩／下一關／回地圖
   → 愛心用完 → 續關
   → 第 10 關後 → [漫畫] → 街區解放 → 地圖；第 50 關後 → 結局漫畫 → 製作名單
```
