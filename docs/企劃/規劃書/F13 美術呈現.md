# F13 美術呈現（Art）
> **正式規則（Spectra）**：[art-presentation](https://github.com/fishon100/pinball-sling/blob/main/docs/spectra/specs/art-presentation/spec.md)（英文規則＋中文說明）。這份規劃書改為背景說明；要改規則請開申請單。
> 主架構：00 主架構規劃書・**風格與外型（單一來源）**：美術風格指南、角色卡・**素材清單**：美術素材清單

## 目的
照企劃的台面設計稿（霓虹夜店舞台 × 街頭噴漆）呈現；打碎的磚留下噴漆，把顏色帶回灰城。
![美術設計-新彈珠台.jpg](../%E5%9C%96/%E7%BE%8E%E8%A1%93%E8%A8%AD%E8%A8%88-%E6%96%B0%E5%BD%88%E7%8F%A0%E5%8F%B0.jpg)

## 功能系統（遊戲裡怎麼畫）
- 背景：暗紫舞台、六角暗紋、聚光燈、人群剪影、霓虹字（RUSH!／BOOM!）、金色手刷 HIT!、霓虹塗鴉（每區＋台面高度快取一張）
- 軌道：深色金屬底＋霓虹燈管（圓弧金＋粉、側牆青）；磚＝銀色金屬鉚釘板；彈跳柱＝青色霓虹環；滑板＝粉紅 SHOOT! 膠囊＋鉻滑軌；發射道＝玻璃管
- 碎磚噴漆濺痕留整關；過關整面噴滿
- 對照表（哪些已做、哪些還沒）：美術風格指南 的「台面設計稿」段落
- 鏡頭：開場 3D 俯衝、最後一磚慢動作特寫、首領登場拉近；需要操作時一定看得到滑板／擋板
- 目前全部程式繪製（占位）；正式素材到位後換成圖檔
