# F14 聲音與震動（Audio／Haptics）
> **正式規則（Spectra）**：[audio-and-haptics](https://github.com/fishon100/pinball-sling/blob/main/docs/spectra/specs/audio-and-haptics/spec.md)（英文規則＋中文說明）。這份規劃書改為背景說明；要改規則請開申請單。
> 主架構：00 主架構規劃書・**素材清單**：音樂素材清單、音效素材清單

## 目的
彈射感的一半靠聲音與震動回饋。

## 功能系統
### 音樂
程式合成 boom-bap 節拍，每區速度與調性不同（五個街區）；連擊 ≥4、首領關、暴怒時疊加樂器（強度 0／1／2）

### 音效（19 種，目前程式合成）
flipper（滑板／擋板）、launch、brickHit、brickBreak（連擊越高音越高）、bucket、bumper、sling、wall、drain、save、combo、clear、lose、achievement、card、bossHit、bossRegen、spray、ui

### 震動（手機；暫停選單可關）
| 事件 | 震動 |
|---|---|
| 拉發射桿 | 每 2 成 6ms |
| 發射 | 20ms |
| 滑板擊球 | 16ms；打邊邊 24ms |
| 擋板擊球 | 12ms |
| 碰到磚／碎磚 | 8ms／18ms＋連擊數（最多 38ms） |
| 油漆桶 | 40-30-60 |
| 彈跳柱／阿鰭／彈弓 | 14／14／10ms |
| 首領受傷 | 28ms |
| 連擊里程碑 | 30-40-30-40-60 |
| 掉球 | 90-50-160 |
| 過關 | 60-50-140 |

## 介面
U-pause：音效／音樂／震動開關；U-title：音樂開關

## 程式位置
`audio.js`；`game.js`：`vibrate`、各事件
