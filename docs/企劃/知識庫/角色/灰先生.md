# 灰先生
> 00 知識庫總覽・遊戲裡的位置：`data.js` 的 `SR.SPEAKERS.grey`；漫畫繪圖 `comic.js` 的 `CHAR.grey／greyYoung`；首領造型 `art.js` 的 `boss()`；玩法 F07 首領灰先生・美術素材：美術素材清單・角色

## 基本
| 項目 | 內容 |
|---|---|
| 身分 | 整潔局的人（反派 → 和解）；年輕時是畫家，親手做了這台彈珠台 |
| 個性 | 冷硬、話少；其實是怕自己的畫再被刷掉 |
| 說話方式 | 命令句、短；最後變得遲疑 |
| 對話框顏色 | `#9a9aa3` |

## 外型
灰色大衣、墨鏡（兩片鏡片）、沒有表情。年輕版：沒有墨鏡、拿畫筆、回憶格泛黃。首領造型：灰色大方塊、墨鏡、噴漆罐皇冠。

## 表情
| 代號 | 用在 |
|---|---|
| stern | 平常（嚴肅） |
| sad | 動搖、和解 |
| back | 背影（不回答） |
| 年輕版 happy／back | 回憶 |

## 在故事裡
每區首領前登場；第 3 區拔掉機台插頭；第 4 區揭曉過去；第 5 區結尾和小葵一起畫完向日葵。

## 在玩法裡
每區第 10 關的首領：左右移動、補灰磚、血量低會暴怒（F07 首領灰先生）。
