# 小葵
> 00 知識庫總覽・遊戲裡的位置：`data.js` 的 `SR.SPEAKERS.kid`；漫畫繪圖 `comic.js` 的 `CHAR.kid`・美術素材：美術素材清單・角色

## 基本
| 項目 | 內容 |
|---|---|
| 身分 | 主角，愛畫畫的小女孩 |
| 個性 | 安靜、勇敢、不放棄；相信顏色不會消失 |
| 說話方式 | 短句、直接，不說教 |
| 對話框顏色 | `#ffb21f` |

## 外型
黃色帽 T、短髮、大眼睛；粗黑描邊、扁平高彩度（與噴漆美術一致）。

## 表情
| 代號 | 用在 |
|---|---|
| sad | 只能把畫藏起來、回憶時 |
| wow | 發現彈珠台、驚訝 |
| determined | 下決心（面對灰先生） |
| happy | 牆開花、和解 |

## 在故事裡
畫的向日葵只能藏在抽屜；在老遊樂場投下最後一枚硬幣，和噴噴一起打開灰城的牆；最後陪灰先生一起畫完大牆上的向日葵。

## 在玩法裡
不在台面上出現；玩家就是「在玩機台的小葵」。
