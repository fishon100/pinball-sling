# 噴噴
> 00 知識庫總覽・遊戲裡的位置：`data.js` 的 `SR.SPEAKERS.pinky`；繪圖 `art.js` 的 `pinky()`（HUD、標題、開場、漫畫共用）・美術素材：美術素材清單・角色

## 基本
| 項目 | 內容 |
|---|---|
| 身分 | 住在老彈珠台裡的噴漆精靈；玩家的引導員 |
| 個性 | 活潑、愛鼓勵人；被拔插頭後變得虛弱 |
| 說話方式 | 驚嘆句多、短、熱情 |
| 對話框顏色 | `#ff3ea5` |

## 外型
粉紅色圓胖身體、兔子般的長耳朵（內側深粉紅）、頭頂一道黑色縫線、白底紅瞳的大眼睛、咧嘴大笑露出一排白牙、短短的手；粗黑描邊。灰色版：全身變灰、瞳孔變灰（第 3 區被拔插頭後）。
（參考：企劃提供的噴漆牆角色 → 00 媒體庫總覽・參考圖）

## 表情
| 代號 | 用在 |
|---|---|
| happy | 平常、過關、鼓勵（會彈跳、揮手） |
| idle | HUD 待機 |
| wow | 提醒、驚訝（圓嘴） |
| sad | 掉球、被拔插頭（下彎嘴、皺眉） |
| 灰色版 | 第 3～4 區 |

## 在故事裡
被小葵的硬幣叫醒；說明機台魔法；被灰先生拔插頭後變灰；第 4 區結尾臉頰回來一點粉紅。

## 在玩法裡
HUD 左上角頭像＋對話泡泡（教學、提醒、歡呼）；開場動畫從機台跳出來。
