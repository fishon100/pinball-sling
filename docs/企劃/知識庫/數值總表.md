# 數值總表
> 00 知識庫總覽・**單一來源**：遊戲裡的位置 `web/street/js/tuning.js`（噴漆闖關專用）與 `data/tuning.json`（v2 手感，Godot 共用）。改這裡後對 AI 說「**同步數值總表**」，AI 會改設定檔、跑測試、用擬人玩家重量難度。
