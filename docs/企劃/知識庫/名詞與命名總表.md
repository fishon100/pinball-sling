## 台面元件與物件（C）
### 鋼珠
C-ball。也有人叫「彈珠、球」。
### 滑板
C-paddle「噴漆滑板」。也有人叫「打板」。大／中／小三種尺寸 → F02 滑板操作
### 擋板
C-flipper-L／R「左／右擋板」。經典模式 → F03 經典擋板操作
### 發射桿
C-plunger。也有人叫「彈簧、拉柄」。黃色拉柄 knob、彈簧 spring、托盤 plate → F04 發射桿
### 發射道
C-lane。右側；出口有單向門 C-gate
### 頂部圓弧
C-arc。也有人叫「軌道」
### 側牆
C-wall。也有人叫「牆壁」
### 彈跳柱
C-bumper「彈跳柱」＝**企劃說的「中柱」**、英文 pop bumper。噴漆罐造型
（參考圖「名詞參考-彈跳柱（中柱）.png」只放在 Obsidian）
### 彈力牆
C-rubber。也有人叫「橡膠、反彈牆」
### 阿鰭（會游的彈跳柱）
C-fish → 阿鰭
### 彈弓
C-sling（slingshot）。只在擋板模式
### 漏斗、導球片
C-funnel。也有人叫「回球道」。只在擋板模式
### 擋柱
C-post。只在擋板模式
### 落點圈
C-landing。輔助
### 灰先生（首領）
C-boss。也有人叫「首領、王」 → 灰先生
### 救球柱（已移除）
~~center post~~：擋在出口的柱子。已移除，違反彈珠基本架構（第 4 輪）

## 磚塊（B）
B-grey 灰磚（1～5 血）、B-bucket 油漆桶、B-gift 道具磚 ★、B-boss 灰先生 → F06 磚塊與關卡

## 輔助（A）
A-preview 彈道預覽、A-landing 落點提示、A-timing 擋板時機提示、A-ballsave 球保險、A-finisher 收尾輔助 → F10 新手輔助與教學

## 介面（U）
U-opening 開場、U-title 標題、U-map 地圖、U-control 操作方式、U-gallery 劇情回放、U-achievements 成就、U-stage-intro 關卡開場、U-play 遊玩、U-pause 暫停、U-clear 過關演出、U-result 結算、U-runover 續關、U-district-free 街區解放、U-credits 製作名單、U-hud-*（HUD 元件）→ F12 介面

## 角色（CH）
CH-kid 小葵、CH-pinky 噴噴、CH-fish 阿鰭、CH-grey 灰先生、CH-citizen／CH-boy 配角

## 遊戲名詞
| 名詞 | 意思 |
|---|---|
| 一輪 | 從選的關卡開始，到回地圖或愛心用完 |
| 愛心 | 生命，一輪 3 顆、過關回 1、最多 5 |
| 掉球 | 球從底部掉出去，扣 1 顆愛心（球保險中不扣） |
| 連擊 | 球離開滑板後連續打到磚／柱的次數 |
| 續關 | 愛心用完投幣，從這關重來（分數減半、最多銅牌） |
| 台面配置 | 每關的彈跳柱、彈力牆、阿鰭擺法（15 種） |
| 街區 | 5 區，每區 10 關 → 五個街區 |
