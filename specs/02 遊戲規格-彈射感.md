# 遊戲規格 v1｜彈射感

> 這是 SDD 的「規格」：AI 照這份實作，人照這份驗收。改需求就改這份。

## 1. 遊戲概要
- 類型：直向單桌彈珠台（手機直拿可玩）
- 一局 3 顆球；球掉進中間出口就失去一顆
- 得分：撞彈跳柱（Bumper）100、彈弓（Slingshot）10、通過上方三個燈道（Lane）各 50
- 三個燈道全亮 → 倍率 +1（最高 x5）；按擋板會讓亮燈輪轉，可以「瞄準」沒亮的燈道

## 2. 「彈射感」是什麼？拆成 5 個要素
| 要素 | 玩家感受 | 怎麼做 |
|---|---|---|
| **擋板爆發力** | 「啪」一下很脆，不黏 | 擋板上舉極快（≈35ms），下放較慢；球的出射速度＝擋板該點的線速度（尖端打得比根部遠） |
| **可控性** | 我想打哪裡就打得到 | 擋板打點不同，角度不同；按住可以「接球」再瞄準 |
| **重量感** | 球像鋼珠，不像氣球 | 重力強、牆面反彈低（0.45）、擋板反彈更低（0.3） |
| **撞擊回饋（打擊感）** | 撞到東西很爽 | 頓幀（hit-stop）＋鏡頭震動＋閃光＋音效＋手機震動 |
| **穩定性** | 球不會亂穿牆、卡住 | 物理子步進（每幀 8 次）＋限速 |

## 3. 手感參數（單一真相來源：`tuning.json`）
| 參數 | 預設 | 說明 |
|---|---|---|
| `ball.gravity` | 1400 px/s² | 台面傾斜感，越大球越重越快 |
| `ball.max_speed` | 2600 px/s | 最高速，防穿牆 |
| `ball.restitution_wall` | 0.45 | 牆反彈係數 |
| `ball.friction` | 0.04 | 碰撞時的表面摩擦 |
| `flipper.length` | 72 px | 擋板長度 |
| `flipper.stroke_deg` | 58° | 擋板擺動角度 |
| `flipper.up_speed_deg_s` | 1700 °/s | 上舉角速度（≈35ms 打完） |
| `flipper.down_speed_deg_s` | 800 °/s | 下放角速度 |
| `flipper.restitution` | 0.3 | 擋板本身反彈 |
| `flipper.power` | 0.8 | 擋板線速度傳給球的比例 |
| `plunger.min_speed` / `max_speed` | 900 / 2300 | 發射力道範圍 |
| `plunger.charge_time` | 0.9 s | 蓄滿力時間 |
| `bumper.kick_speed` | 950 px/s | 彈跳柱彈開速度 |
| `sling.kick_speed` | 800 px/s | 彈弓彈開速度 |
| `juice.hitstop_ms` | 35 ms | 頓幀長度 |
| `juice.shake_px` | 6 px | 震動幅度 |
| `juice.vibrate_ms` | 15 ms | 手機震動 |
| `physics.substeps` | 8 | 每幀物理子步數 |

> 調整紀錄：v1 草案的上舉速度 2000°/s、力道 1.0 會讓擊球速度貼到最高速上限、失去打點差異，實作時調成 1700°/s、0.8。

數值／企劃用網頁原型的「調參面板」即時調整 → 按「匯出 JSON」→ 貼回 `pinball-godot/data/tuning.json`，Godot 版自動吃到同一份手感。

## 4. 驗收條件（Acceptance Criteria）
> 標 🤖 的有自動測試（網頁原型與 Godot 都有）；標 👤 的需要人在手機上試玩確認
> 最近一次結果：2026-10-03，網頁原型與 Godot 4.7 皆 6/6 通過，AC1–AC5 數值兩邊完全一致

- [x] **AC1** 🤖 擋板從靜止到全舉 ≤ 50 ms ｜實測 35.4 ms
- [x] **AC2** 🤖 球在擋板尖端被全速擊中，出射速度 ≥ 1500 px/s ｜實測 1895 px/s
- [x] **AC3** 🤖 擋板尖端擊球速度 > 根部 ×1.2 ｜實測 尖 2006 / 根 1101
- [x] **AC4** 🤖 以最高速撞牆，球不會穿出桌面 ｜32 方向、19,815 子步，0 次穿牆（子步數改成 1 會穿牆 22 次 → 證明 8 子步是必要的）
- [x] **AC5** 🤖 球撞彈跳柱後速度 ≥ `bumper.kick_speed` ｜實測 950 / 950
- [x] **AC6** 🤖 球速永遠 ≤ `ball.max_speed` ｜20 秒隨機遊玩，最高 2528 / 2600
- [x] **AC7** 👤 按住擋板可以把球接住停在擋板上 ｜模擬驗證：球停在擋板根部角落、速度歸零；仍建議手機試玩確認
- [ ] **AC8** 👤 撞擊時有頓幀、震動、閃光、音效、手機震動 ｜已實作，待手機試玩（iPhone Safari 不支援網頁震動）
- [ ] **AC9** 👤 手機直向可玩：左半＝左擋板、右半＝右擋板、球在發射道時按住右半蓄力 ｜已實作，待手機試玩
- [ ] **AC10** 👤 企劃試玩評價「彈射感到位」（主觀，最終關卡）
