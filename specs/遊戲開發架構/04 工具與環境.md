# 04 工具與環境
> 總覽：[[00 開發架構總覽]]。分成：**開發**、**產出**（做出內容）、**管理**（存放、版本、協作）、**預覽與通知**。

## 開發
| 工具 | 用途 |
|---|---|
| Claude Code（Claude 桌面版 Code 分頁） | 主控 AI：寫程式、跑測試、部署、寫文件 |
| `/goal` | 給 AI 一個完成條件，它會一直做到條件達成、不中途問問題；提早停：`/goal clear` |
| Remote Control | 電腦上的 Claude 繼續跑，人在手機 Claude App 看進度、下指令（電腦要保持開機） |
| Godot 4.7 | 正式版遊戲引擎 |
| 網頁原型（HTML5 Canvas＋JavaScript） | 快速驗證設計，手機直接玩 |
| WebAudio | 程式即時合成聲音（占位） |
| Codex／Copilot | 第二家 AI 程式審查 |

## 產出（做出內容）
| 類別 | 工具 |
|---|---|
| 文字：企劃、劇本、台詞、文案 | **ChatGPT**、Claude |
| 圖：角色、場景、UI、圖示 | **ChatGPT（GPT Image）**、Midjourney、Gemini |
| 音樂 | Suno |
| 音效、語音 | ElevenLabs（Sound Effects／Voice） |
| 數值 | 試算表、網頁調參面板、AI 模擬 |

## 管理（存放、版本、協作）
| 類別 | 工具 | 放什麼 |
|---|---|---|
| 文件、知識庫 | **Obsidian**（＋Local REST API 外掛＋mcp-obsidian，讓 AI 直接讀寫） | 規劃書、劇情、角色、數值、回饋、日誌 |
| 美術 | **Figma** | 設計稿、角色設定圖、UI、素材精修與版本 |
| 程式與遊戲用素材 | **GitHub**（Git） | 程式碼、遊戲實際讀取的圖檔／音檔 |
| 大型原始檔 | 雲端硬碟（Google Drive 等） | 音樂原檔、高解析原圖 |

## 預覽與通知
| 工具 | 用途 |
|---|---|
| GitHub Pages | 手機直接開的預覽網址 |
| Claude Artifact | 快速原型、文件分享（私人連結） |
| Railway | 需要伺服器的遊戲才用 |
| ntfy App＋Windows 通知 | 每次完成都同時通知電腦與手機，附預覽連結 |
| 部署腳本 `tools/deploy.ps1`、`tools/notify.ps1` | 一鍵：測試 → 匯出 → 推上 GitHub → 等網頁更新 → 通知 |

### 手機通知第一次設定
1. 安裝 ntfy App → 訂閱 `tools/notify.config.json` 裡的主題名稱（主題名稱等於密碼，不放公開 repo）
2. 允許通知；收到「🔔 通知測試」就成功
