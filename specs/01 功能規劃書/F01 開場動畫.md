# F01 開場動畫（OpeningSequence）
> 主架構：[[00 主架構規劃書]]

## 目的
第一次打開遊戲時，用約 7 秒讓玩家感受「灰城 → 老機台 → 顏色炸開」的主題，帶出招牌與噴噴。

## 玩家體驗
| 時間 | 畫面 | 聲音／震動 |
|---|---|---|
| 0 | **投幣畫面**：灰色天際線、灰色的 SPRAY RUN、閃爍「INSERT COIN」、硬幣。點一下＝投幣 | 投幣聲、震動 30ms |
| 0～2.6 秒 | 旁白「很久很久以前，有一座灰城……」 | — |
| 1.2 秒 | 老彈珠台閃爍亮起 | 叮 |
| 2.6～4.2 秒 | 噴漆一團一團炸開（28 團、6 色） | 碎磚聲漸強、細震 |
| 4.3 秒 | SPRAY／RUN 招牌砸下 | 過關音、震動 |
| 5.2 秒 | 噴噴從機台跳出來；「把灰城砸回彩色！」 | 連擊音 |
| 7 秒 | 自動進標題 | — |

## 功能系統
- 只有**第一次**進遊戲自動播（存檔 `seenOpening`）；標題「重看開場」可再看
- 播放中點一下可跳過（0.8 秒後）
- 先「投幣」的原因：瀏覽器要先點一下才能播聲音；這一下同時呼應劇情（小葵投下最後一枚硬幣 → [[劇情腳本]] 第 1 段）
