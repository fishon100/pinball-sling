# 美術風格指南
> [[00 媒體庫總覽]]・產出工具：ChatGPT（GPT Image）、Midjourney、Gemini・管理工具：**Figma**（風格板、色票、元件庫）
> 遊戲裡的位置：`art.js`、`comic.js`（目前程式繪製）

## 風格
**美式街頭噴漆**：粗黑描邊、高彩度、霓虹光、滴漆；2.5D（磚塊擠出、過場 3D 傾斜）。
**灰城是純灰**（RGB 三值相同，不帶色偏）；被打開的地方才有顏色。
![[美術參考-噴漆牆1.png|200]] ![[美術參考-噴漆牆2.png|200]]

## 規則
| 項目 | 規格 |
|---|---|
| 描邊 | 黑 `#111114`；台面邊框 12px、磚塊 3.5px、角色 4～6px；阿鰭用咖啡色 `#4a2a17` |
| 配色 | 每區 3 色＋發光色 → [[五個街區]] |
| 霓虹 | 邊框外光、彈跳柱常亮光圈、球的拖尾 |
| 牆面 | 街區色打光＋巨大半透明噴漆字（SPRAY／RUN／街區英文名） |
| 碎磚 | 噴漆濺痕留在牆上整關；過關整面牆噴滿 |
| 字體 | 英文 Permanent Marker／Bungee；中文 Noto Sans TC 900 |
