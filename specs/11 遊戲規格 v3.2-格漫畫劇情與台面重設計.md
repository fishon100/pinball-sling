## 1. 名詞對齊（這輪最重要的修正）

|---|---|---|---|

## 3. 格漫畫劇情（童話故事標準）
### 3.1 故事（起承轉合只在文件用，畫面不顯示）
- **開場**「很久很久以前，有一座城，叫做灰城。」所有牆都必須是灰色。
- 小女孩**小葵**愛畫向日葵，在快拆的老遊樂場找到一台舊彈珠台，投下最後一枚硬幣 → 牆上的塗鴉角色**噴噴**醒來。
- 在台子裡打碎灰牆 → 城裡真的牆一面面恢復顏色。
- 反派：整潔局的**灰先生**。拔掉機台插頭，噴噴變灰。
- 河堤回憶（泛黃畫格）：這台彈珠台是灰先生年輕時做的，他的畫曾被塗掉。
- 結局：大牆上那幅沒畫完的向日葵，兩人一起完成；「從此以後……彩城」；「顏色可以被蓋住，但不會消失。——完——」

### 3.2 漫畫演出規則（研究整理）
| 規則 | 實作 |
|---|---|
| 依序帶出：背景框 → 角色 → 對話框 | 框 0～0.32 秒、角色彈入 0.28 秒起、旁白 0.45 秒、對白 0.62 秒起每句隔 0.3 秒，打字機 34 字／秒 |
| 先給「場景大圖」（establishing shot），再給特寫 | 每段第一頁第一格是全景 |
| 大格＝慢、小格＝快 | 情緒點用整列大格，動作用並排小格 |
| 情緒節拍：事件 → 無聲停頓 → 反應 | 噴噴變灰、回憶後各有一格沒有對白 |
| 對話框依閱讀順序、尾巴指向說話者的臉、不可蓋臉 | 自動測試 AC-S18 檢查 |
| 一句 ≤ 30～35 字 | 每句 ≤ 32 字（測試） |
| 中文斷行不讓標點出現在行首 | 禁則處理 |
| 回憶用泛黃色調 | sepia 畫格 |

- 操作：點一下＝補完這一格 → 下一格 → 翻頁；右上「跳過劇情」
- 漫畫當關卡轉場：開場、每區開頭、首領前、清區後、結局，共 15 段 23 頁

## 4. 台面重設計（v3.3，參考 3D Space Cadet）
網頁版 Space Cadet：https://lrusso.github.io/3DPinballSpaceCadet/3DPinballSpaceCadet.htm

### 4.1 實際玩過的觀察（打了 3 顆球）
- 發射：右側發射道 → 長長的頂部環道（orbit），球繞一圈才落下，第一下就會打到上方元件
- **彈跳柱都是「一群一群」放**：上方中央 3 顆三角形一組（左上另 1 顆）、左側紫色坡道區也 3 顆一組。球進到群裡會連彈好幾次，分數一直跳，這段時間球不會回到擋板
- 導軌（rail）、回球道把球從上方帶回擋板內側（inlane）；兩側有外線道（outlane），掉進去就死——**掉球是彈珠台本來就有的風險**（呼應企劃說的「玩家會死亡是必然的」）
- 實際打的結果：沒接好的球很快就從中間或外線道掉下去，3 顆球都不長；真正讓一顆球「活很久」的是球在上半部彈跳柱群裡打轉的時間
- 其他：中央亮燈目標環、右側落下靶、任務系統（打任務靶選任務）——是計分深度，不影響存活，這版不做

### 4.2 量測（新手自動玩家：反應慢、30% 漏接；輔助全關；第 1 區 9 關 × 5 局＝45 局）
先做 🟡 的導軌、牆壁，再看要不要加中柱（企劃指示）：

| 設計 | 每關掉幾顆愛心 | 平均過關秒數 | 結論 |
|---|---|---|---|
| 現在的台面 | 9.67 | 136 | 基準 |
| 上半部側邊導軌（往牆斜） | — | — | ❌ 和牆形成死角，57 次卡球 |
| 上半部側邊導軌（往中間斜） | 12.13 | 158 | ❌ 球被導到中間，更容易從擋板中間掉 |
| 中段浮空導軌 | 12.69 | 152 | ❌ 同上 |
| 中段側牆橡膠（會彈的牆） | 8.78 | 123 | 小幅改善 |
| 下段導軌（往外／往內） | 2.73／9.67 | 265／128 | ❌ 往外的會讓球停住；往內沒效果 |
| 加高彈弓 | 10.60 | 138 | ❌ |
| 中段兩顆中柱 | 8.73 | 129 | 小幅改善 |
| 下方兩顆中柱 | 14.51 | 209 | ❌ 擋住擋板往上打 |
| 上方中央三角 3 顆 | 5.69 | 89 | 有效，但擋住主射擊線 |
| **兩側三角柱群（每側 3 顆）** | **2.69** | **51** | ✅ 最好 |

👉 結論：導軌、牆壁對存活幫助很小；**企劃的直覺是對的：中柱（彈跳柱）要加，而且要像 Space Cadet 一樣成群放在上半部兩側**，不擋擋板往上打的主線。

### 4.3 定案（v3.3）
- 位置：每側一組三角形 (105,400)、(60,360)、(60,440)，左右對稱；原本的 (56,560)、(304,560) 保留
- 越後面越少（難度提高的因素之一）：每側 **3／3／2／1／1** 顆（第 1～5 區），資料在 `data.js` 的 `DISTRICTS[].cluster`

| 實際遊戲（含各區輔助、各區 4 關 × 10 局） | 新手：舊 → 新 | 進步中：舊 → 新 |
|---|---|---|
| 第 1 區 | 5.10 顆／95 秒 → **2.20 顆／40 秒** | 1.50 → 0.70 顆 |
| 第 2 區 | 2.13 → 0.78 顆 | 0.47 → 0.07 顆 |
| 第 3 區 | 0.53 → 0.03 顆 | 0 → 0 顆 |
| 第 4 區 | 0.72 → 0.35 顆 | 0.13 → 0.03 顆 |
| 第 5 區 | 0.55 → 0.30 顆 | 0.10 → 0.03 顆 |

（第 3 區以後數字小，是因為自動玩家帶著前面拿到的強化卡；第 1 區沒有強化卡最難。）
- 第 1 區新手每關還是會掉約 2 顆愛心（一輪 3 顆，過關回 1 顆）。**要不要再更簡單，請試玩後回饋**；可以調的旋鈕：每側柱數、柱的位置、球保險秒數

### 4.4 自動測試
- AC-S7：每側 3／2／1 顆都測卡球，0 次
- AC-S19（新）：柱子不碰 50 關的任何磚、越後面的區越少、新手每關掉的愛心至少少一半
