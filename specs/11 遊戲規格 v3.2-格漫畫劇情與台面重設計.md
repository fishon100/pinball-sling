## 1. 名詞對齊（這輪最重要的修正）
| 企劃說的 | 正式名詞 | 樣子 | 之前的誤解 |
|---|---|---|---|
| **中柱** | **彈跳柱（pop bumper）** | 台面上圓形、會把球彈開的柱子 | 我做成「擋板中間的救球柱」 |

## 3. 格漫畫劇情（童話故事標準）
### 3.1 故事（起承轉合只在文件用，畫面不顯示）
- **開場**「很久很久以前，有一座城，叫做灰城。」所有牆都必須是灰色。
- 小女孩**小葵**愛畫向日葵，在快拆的老遊樂場找到一台舊彈珠台，投下最後一枚硬幣 → 牆上的塗鴉角色**噴噴**醒來。
- 在台子裡打碎灰牆 → 城裡真的牆一面面恢復顏色。
- 反派：整潔局的**灰先生**。拔掉機台插頭，噴噴變灰。
- 河堤回憶（泛黃畫格）：這台彈珠台是灰先生年輕時做的，他的畫曾被塗掉。
- 結局：大牆上那幅沒畫完的向日葵，兩人一起完成；「從此以後……彩城」；「顏色可以被蓋住，但不會消失。——完——」

### 3.2 漫畫演出規則（研究整理）
| 規則 | 實作 |
|---|---|
| 依序帶出：背景框 → 角色 → 對話框 | 框 0～0.32 秒、角色彈入 0.28 秒起、旁白 0.45 秒、對白 0.62 秒起每句隔 0.3 秒，打字機 34 字／秒 |
| 先給「場景大圖」（establishing shot），再給特寫 | 每段第一頁第一格是全景 |
| 大格＝慢、小格＝快 | 情緒點用整列大格，動作用並排小格 |
| 情緒節拍：事件 → 無聲停頓 → 反應 | 噴噴變灰、回憶後各有一格沒有對白 |
| 對話框依閱讀順序、尾巴指向說話者的臉、不可蓋臉 | 自動測試 AC-S18 檢查 |
| 一句 ≤ 30～35 字 | 每句 ≤ 32 字（測試） |
| 中文斷行不讓標點出現在行首 | 禁則處理 |
| 回憶用泛黃色調 | sepia 畫格 |

- 操作：點一下＝補完這一格 → 下一格 → 翻頁；右上「跳過劇情」
- 漫畫當關卡轉場：開場、每區開頭、首領前、清區後、結局，共 15 段 23 頁

## 4. 台面重設計（🟡，尚未開始，等實際玩過 3D Space Cadet）
企劃要求「請實際玩過，才開始設計」。網頁版 Space Cadet：https://lrusso.github.io/3DPinballSpaceCadet/3DPinballSpaceCadet.htm
（Claude 的瀏覽器分頁在背景時遊戲不會跑，需要把 Claude 視窗與瀏覽器面板顯示在前面才能玩。）

### 4.1 先從截圖觀察到的（待實玩驗證）
- 右側發射道 → 長長的頂部環道（orbit），球會繞一圈再落下
- 上方中央 3 顆彈跳柱一組，左上另有 1 顆；左側紫色坡道區也有 3 顆一組
- 右側導軌（rail）、回球道；中央亮燈目標環；右側落下靶
- 兩側彈弓、內線道（inlane）／外線道（outlane）
- 任務系統：打任務靶選任務

### 4.2 預計要比較的設計（實玩後定案）
- 回球導軌（inlane 導回擋板）→ 讓新手更常接得到球
- 頂部環道 → 發射後先繞一圈、不直接掉
- 彈跳柱群（中柱）數量與位置 → 用新手／進步中／熟練三種自動玩家各 40 局以上量測
