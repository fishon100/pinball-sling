# F12 介面：畫面與 HUD（UI）
> 主軸：[[00 主軸文件]]・程式：`game.js`（畫面函式）、`index.html`（樣式）

## 畫面流程
```
開場動畫（第一次）→ 標題 → 地圖 → [漫畫] → 關卡開場 → 遊玩 ⇄ 暫停
   → 過關演出 → 結算 → 重玩／下一關／回地圖
   → 愛心用完 → 續關畫面
   → 第 10 關後 → [漫畫] → 街區解放 → 地圖；第 50 關後 → 結局漫畫 → 製作名單
```

## 畫面清單
| 代號 | 名稱 | 內容與按鈕 |
|---|---|---|
| U-opening | 開場動畫 | 見 [[02 開場動畫]] |
| U-title | 標題 | 大字招牌、大隻噴噴；開始／成就／音樂／**重看開場**／操作 |
| U-map | 城市地圖 | 5 區卡片；每區 10 格（金／銀／銅、▶ 下一關、王）可直接點選關；出發／繼續；**劇情回放**／成就／操作／重看教學／回標題 |
| U-control | 操作方式 | 🛹 滑板（推薦）／🎰 經典擋板 |
| U-gallery | 劇情回放 | 16 段漫畫清單 |
| U-achievements | 成就 | 統計＋19 個成就 |
| U-stage-intro | 關卡開場 | STAGE N、關卡名、「台面：○○」，3D 俯衝鏡頭 |
| U-play | 遊玩 | 見下方 HUD |
| U-pause | 暫停 | 繼續／音效／音樂／**震動**／放棄回地圖 |
| U-clear | 過關演出 | 慢動作特寫 → 整面牆噴滿 → WALL CLEARED! |
| U-result | 結算 | 獎牌、抽到的強化、時間／掉的愛心／連擊／分數；**下一關／重玩這關／回地圖** |
| U-runover | 續關 | 投幣續關（從這關重來）／整區重來／回地圖 |
| U-district-free | 街區解放 | 本輪統計、街區獎勵道具 |
| U-credits | 製作名單 | |
