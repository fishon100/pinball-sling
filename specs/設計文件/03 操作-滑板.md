# F02 滑板操作（Paddle）— 預設操作
> 主軸：[[00 主軸文件]]・相關：[[04 操作-經典擋板]]、[[05 發射桿]]、[[16 難度與平衡]]
> 程式：`physics.js` 的 `movePaddle／collidePaddle／paddleDims／paddleRange`；手感參數：`tuning.js` 的 `paddle`

## 目的
經典兩支擋板要「抓時機」、手機要兩手、電腦滑鼠來不及點（第 5 輪回饋）。滑板只要**追著球移動**，一根手指或滑鼠就能玩。

## 玩家體驗
- 手機：手指左右滑；電腦：**移動滑鼠就好，不用點**（滑鼠移出遊戲畫面也會跟著，停在最左／最右）；鍵盤 ←／→
- 打在滑板**中間**＝直直往上；越靠**邊邊**越斜（最斜 55°）→ 可以瞄準磚塊
- 擊球回饋：滑板壓扁發光、接觸點往出球方向噴一團漆；打邊邊（斜射）更大更亮並顯示 ↖／↗；震動 16～24ms
- 遊玩中滑鼠游標隱藏（滑板就是游標）

## 規則與數值
| 項目 | 數值 | 說明 |
|---|---|---|
| 尺寸（全寬） | 小 80／**中 112**／大 152 px | 一般關卡＝中；首領關＝小；道具「寬板」＝大（12 秒） |
| 移動範圍 | 左牆 x=20 到發射道內牆 x=340（**整個台面寬**） | 第 6 輪：不限制寬度範圍 |
| 出球速度 | 1550 px/s（強化「強力擋板」每級 +12%） | 固定，讓手感可預期 |
| 最斜角度 | 55° | |
| 跟手速度上限 | 2600 px/s | 避免瞬移穿球 |
| 帶球 | 滑板移動速度的 15% 加到球的水平速度 | |
| 高度 | y=948 | |

- 台面底部（滑板模式）：**沒有彈弓、沒有漏斗**，整片打開，球從滑板旁邊掉下去就是掉球

## 驗收
- AC-S21：中間直上、邊邊 ≥35°、速度固定、移動有上限、球不會停在滑板上、S<M<L、首領關＝小、範圍 20～340、沒有彈弓
- AC-S20：第 1 區擬人新手每關 ≤1 顆愛心
