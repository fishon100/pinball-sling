# F01 開場動畫（OpeningSequence）
> 主軸：[[00 主軸文件]]・程式：`game.js` 的 `openingScreen／tickOpening／drawOpening`

## 目的
第一次打開遊戲時，用 7 秒讓玩家感受到「灰城 → 老機台 → 顏色炸開」的主題，並帶出招牌與噴噴。

## 玩家體驗（依序）
| 時間 | 畫面 | 聲音／震動 |
|---|---|---|
| 0 | **投幣畫面 InsertCoin**：灰色天際線、灰色的 SPRAY RUN、閃爍的「INSERT COIN」、硬幣。點一下＝投幣 | 投幣聲、震動 30ms |
| 0～2.6 秒 | 旁白「很久很久以前，有一座灰城……」 | — |
| 1.2 秒 | 老彈珠台閃爍亮起 | 叮 |
| 2.6～4.2 秒 | 噴漆一團一團炸開（28 團，6 種顏色） | 碎磚聲漸強、細震 |
| 4.3 秒 | SPRAY / RUN 招牌砸下來 | 過關音、震動 |
| 5.2 秒 | 噴噴從機台跳出來；「把灰城砸回彩色！」 | 連擊音 |
| 7 秒 | 自動進標題 | — |

- 播放中點一下可以跳過（0.8 秒後）
- 為什麼要先「投幣」：瀏覽器規定要先點一下才能播聲音；把這一下變成「投下硬幣」，同時呼應劇情（小葵投下最後一枚硬幣）

## 規則
- 只有**第一次**進遊戲會自動播（存檔 `seenOpening`）；標題畫面「重看開場」可以再看

## 元件與命名
| 代號 | 名稱 |
|---|---|
| U-opening-coin | 投幣畫面 |
| U-opening-play | 開場動畫本體 |
| U-title-replayOpening | 標題的「重看開場」按鈕 |
