# 噴漆闖關 SPRAY RUN — 主軸文件

> 這份是**主軸**：遊戲是什麼、核心玩法、所有功能的索引。每個功能的細節都在獨立的分冊（下方連結）。
> 📱 遊戲：https://fishon100.github.io/pinball-sling/street/ ・🧪 自動測試：https://fishon100.github.io/pinball-sling/street/test.html
> 舊的版本規格（02、06、08、10、11、12）是「每一輪改了什麼」的紀錄；**目前的完整設計以這個資料夾為準**。

## 1. 一句話
**把灰城砸回彩色**：在一台老彈珠台裡用滑板（或擋板）把鋼珠打上去、打碎灰色磚牆，每打開一面牆，城裡真的那面牆就會開出顏色。

## 2. 設計支柱
| 支柱 | 意思 | 怎麼做到 |
|---|---|---|
| 彈射感 | 擊球那一下要爽、可預期 | 滑板打點決定角度、固定出球速度；頓幀、震動、噴漆濺開（[[03 操作-滑板]]、[[15 聲音與震動]]） |
| 人人都能玩 | 新手第 1 區每關 0～1 顆愛心 | 用「擬人玩家」量難度；矮台面、輔助逐區關閉（[[16 難度與平衡]]） |
| 每關都新鮮 | 不重複 | 15 種台面配置、13 種文字磚圖案、阿鰭（[[06 台面與配置]]、[[07 磚塊與關卡]]） |
| 有故事的街頭 | 童話＋格漫畫 | 16 段漫畫轉場、可回放（[[01 世界觀與完整劇情線]]、[[12 漫畫系統]]） |
| 大膽的噴漆美術 | 粗描邊、霓虹、高彩度 | [[14 美術風格與角色]] |

## 3. 核心循環
```
選關（地圖）→ 漫畫轉場 → 拉發射桿 → 用滑板接球、打碎灰磚
   → 過關：獎牌（依愛心）＋抽一罐強化 → 重玩／下一關／回地圖
   → 第 10 關打倒灰先生 → 解放這一區 → 下一區
```
- 一輪 3 顆愛心，過關回 1 顆（最多 5）；愛心用完可投幣續關
- 5 區 × 10 關＝50 關，越後面台面越高、輔助越少
