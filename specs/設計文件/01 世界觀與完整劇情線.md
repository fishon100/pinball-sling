# 世界觀與完整劇情線
> 主軸：[[00 主軸文件]]・演出方式：[[12 漫畫系統]]・資料：`web/street/js/data.js` 的 `SR.COMICS`

## 目的
讓玩家知道「為什麼要打碎磚牆」，而且故事要像童話一樣好懂、不搞笑、有溫度。

## 童話骨架
很久很久以前（設定）→ 願望 → 魔法幫手 → 三次考驗 → 最低潮 → 真相與轉變 → 從此以後（結局＋寓意）
（設計用的「起承轉合」只在文件裡用，**遊戲畫面不顯示**——第 3 輪回饋）

## 世界觀
- **灰城**：規定所有的牆都必須是灰色。誰畫上顏色，第二天就會被刷掉。
- **老彈珠台**：快拆掉的老遊樂場裡的一台機台。在台子裡打碎灰牆，城裡真的那面牆就會開出顏色。
- **寓意**：顏色可以被蓋住，但不會消失。

## 寫作規則
- 童話語氣、不搞笑；每句對白 ≤ 32 字（自動測試 AC-S18）
- 開場「很久很久以前」、結尾「從此以後」（AC-S16）
- 玩家不是彈珠，玩家是在玩機台的人（第 3 輪回饋）
