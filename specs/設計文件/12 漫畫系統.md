# F11 漫畫系統與劇情回放（Comic／Gallery）
> 主軸：[[00 主軸文件]]・劇情內容：[[01 世界觀與完整劇情線]]・程式：`comic.js`・資料：`SR.COMICS`、`SR.COMIC_TITLES`

## 目的
用格漫畫說故事、當關卡轉場（第 4 輪：背景框 > 角色 > 對話框依序帶出）。

## 演出規則
| 規則 | 實作 |
|---|---|
| 依序帶出 | 框 0～0.32 秒 → 角色彈入（0.28 秒起、每個隔 0.12） → 旁白 0.45 秒 → 對話框（0.62 秒起、每句隔 0.3）＋打字機 34 字／秒 |
| 先全景後特寫 | 每段第一格是場景大圖 |
| 大格慢、小格快 | 情緒點整列大格、動作並排小格 |
| 事件 → 無聲 → 反應 | 關鍵處留一格沒有對白 |
| 對話框 | 閱讀順序、尾巴指向說話者頭部、不可蓋臉、不出框、≤32 字 |
| 回憶 | 泛黃（sepia）＋網點 |
| 中文斷行 | 標點不放行首 |
- 操作：點一下＝補完這一格 → 下一格 → 翻頁；右上「跳過劇情」

## 劇情回放（U-gallery）
地圖「📖 劇情回放」：16 段依順序列出，看過的可以點來重看（存檔 `seenComic`）

## 元件與命名
U-comic 漫畫層、U-comic-skip 跳過按鈕、U-gallery 劇情回放頁；背景場景 30 種（cityGrey、arcade、machineGlow、riverside…）；角色 kid／pinky／pinkyGrey／grey／greyYoung／citizen／boy／fish

## 驗收
AC-S16、AC-S18（版面：不蓋臉、不出框、不重疊）、AC-S22（每段都能回放）
