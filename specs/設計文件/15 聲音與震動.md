# F14 聲音與震動（Audio／Haptics）
> 主軸：[[00 主軸文件]]・程式：`audio.js`（WebAudio 即時合成）、`game.js` 的 `vibrate`

## 音樂
程式合成的 boom-bap 節拍，每區不同速度（88～100 BPM）與調性；連擊 ≥4、首領關、暴怒時疊加樂器（強度 0／1／2）

## 音效（16 種）
flipper（滑板／擋板）、launch（發射）、brickHit、brickBreak（連擊越高音越高）、bucket、bumper、sling、wall、drain、save、combo、clear、lose、achievement、card、bossHit、bossRegen、spray、ui

## 震動（手機；暫停選單可關）
| 事件 | 震動 |
|---|---|
| 拉發射桿 | 每 2 成 6ms「喀」 |
| 發射 | 20ms |
| 滑板擊球 | 16ms；打邊邊 24ms |
| 擋板擊球 | 12ms |
| 碰到磚 | 8ms |
| 碎磚 | 18ms＋連擊數（最多 38ms） |
| 油漆桶 | 40-30-60 |

| 首領受傷 | 28ms |

| 掉球 | 90-50-160 |
| 過關 | 60-50-140 |
