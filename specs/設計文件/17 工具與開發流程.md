# 工具與開發流程
> 主軸：[[00 主軸文件]]・流程設計：[[01 AI開發流程]]・工具說明：[[04 工具-goal、遠端操控、手機預覽]]

## 使用的工具
| 工具 | 用途 |
|---|---|
| **Claude Code**（Claude 桌面版 Code 分頁） | AI 開發：讀回饋、寫程式、跑測試、部署、寫文件 |
| **Obsidian** ＋ Local REST API 外掛＋ mcp-obsidian | 企劃文件（本資料夾）；AI 可以直接讀寫 |
| **網頁版遊戲**（HTML5 Canvas＋JavaScript，無框架） | 目前的可玩版本：`web/street/` |
| **WebAudio** | 音樂與音效即時合成 |
| **Godot 4.7** | 正式版引擎（目前是 v2 台面，等設計定案移植） |
| **GitHub**（帳號 fishon100、公開 repo pinball-sling） | 程式碼版本控制 |
| **GitHub Pages** | 手機直接開的網址（`/docs` 資料夾） |
| **ntfy**（手機 App）＋ Windows 通知 | 部署完成時電腦、手機都收到通知與連結 |
| **自動測試頁** `/street/test.html` | 22 項驗收（物理、關卡、難度、漫畫版面…） |
| **擬人自動玩家** | 用人的反應速度量難度（[[16 難度與平衡]]） |
| **3D Pinball Space Cadet（網頁版）** | 台面設計參考，實際玩過 |
| PowerShell 腳本 `tools/deploy.ps1`、`tools/notify.ps1` | 一鍵：測試 → 匯出 → 推上 GitHub → 等網頁更新 → 通知 |

## 開發流程（SDD＋TDD）
1. 企劃試玩 → 在 [[05 開發日誌]] 的「第 N 輪」寫 🔴必修／🟡建議／🟢很好
2. 說「看回饋」→ AI 讀回饋，先寫／改設計文件（本資料夾），再寫測試、再寫程式
3. 用擬人玩家量測，達標才算完成；22 項測試全過
4. `deploy.ps1` 部署 → 電腦＋手機通知
5. 開發日誌記錄這輪改了什麼、數據、下一步

## 檔案分工（`web/street/js/`）
| 檔案 | 內容 |
|---|---|
| data.js | 企劃可改的資料：街區、台面配置、關卡圖案、強化、成就、道具、角色、漫畫 |
| tuning.js | 手感參數（滑板、發射、輔助、道具秒數） |
| physics.js | 物理：球、牆、彈跳柱、擋板、滑板、磚塊、鏡頭 |
| rules.js | 規則：強化、道具、首領、獎牌、成就、存檔 |
| art.js | 美術（程式繪製） |
| comic.js | 漫畫播放與畫格繪製 |
| audio.js | 聲音 |
| game.js | 流程、畫面、輸入、開場、教學 |
| tests.js | 自動測試與擬人玩家 |
